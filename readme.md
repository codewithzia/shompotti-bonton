# সম্পত্তি বণ্টন (Shompotti Bonton)

A single-page web app that calculates inheritance distribution according to
Islamic Shariah (Faraid).

## Features
- Enter land area, price per unit, sons, daughters, and wives
- Wife alive/deceased status support
- Correct Shariah shares: wives get 1/8 (with children) or 1/4 (without),
  residue split son:daughter = 2:1
- All monetary values displayed in Bengali numerals and words
- Land unit converter: শতাংশ ⇄ কাঠা ⇄ বিঘা ⇄ একর ⇄ বর্গফুট

## Tech
HTML, Tailwind CSS, vanilla JavaScript — no build step, no dependencies.

Simplified faraid covering wife, sons and daughters only. Other heirs
(parents, siblings) change the ruling — consult a scholar for real cases.
